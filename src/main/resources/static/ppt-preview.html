Self-Hosting Advantage

  • Fully hosted on Landmark's private cloud infrastructure
  • Zero customer data shared with any third-party vendor
  • Full data sovereignty — conversation history, order data & profiles never leave LMG servers
  • No vendor lock-in — we own the code, the model calls, and the data
  • Compliant with internal data governance and security policies
  • Full control over uptime, scaling, and access permissions

What We Are Offering

Flow-Based (Menu & Submenu)

  • Structured navigation with clickable categories
  • Main Menu → Submenu → Action
  • No typing required
  • Track Order · Store Locator · Gift Card · Write to Us · My Profile
  • Ideal for guided navigation

Free Text (Natural Language)

  • User types anything in their own words
  • AI automatically classifies the intent
  • Routes to the correct handler + API
  • Handles typos, variations, mixed queries
  • No rigid structure required

Developer Experience & Comparison

Adding a new feature in LOIPL — 5 steps · ~1–2 hours

  • Create DTO (response shape)
  • Create Tool — API caller with @Tool
  • Create Intent Handler — @Component implements IntentHandler
  • Add one bullet to Intent Classifier prompt
  • Spring auto-discovers — zero manual wiring
